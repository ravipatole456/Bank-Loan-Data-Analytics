# 🏦 Bank Loan Data Analytics | Excel, Power BI & SQL

An end-to-end Bank Loan Data Analytics project using Excel, Power BI, and MySQL to analyze loan performance, verification, delinquency, and default risk.

## 📌 Project Overview

This project focuses on analyzing banking loan data to understand loan portfolio performance and identify important indicators related to loan verification, delinquency, and defaults.

Using Excel and Power BI dashboards alongside MySQL queries, the project transforms raw data into meaningful KPIs and visual insights to support data-driven decision-making.

## 🎯 Business Problem

Financial institutions need to monitor loan performance and identify potential risk indicators to make informed lending decisions.

This project addresses key analytical questions:

- How can overall loan performance be monitored?
- What is the status of loan verification?
- How many loans are delinquent?
- What is the loan default rate?
- How can key loan metrics be presented through dashboards and SQL-based analysis?

## 🛠️ Tools & Technologies

- **Microsoft Excel** — Data analysis, KPI calculations, and dashboard creation.
- **Power BI** — Interactive dashboards, data visualization, and analytical measures.
- **MySQL** — SQL queries for KPI calculations and chart-level analysis.


## 🧠 Skills Demonstrated

- **SQL & Data Analysis:** Aggregate functions, filtering, conditional logic, JOIN, GROUP BY, ORDER BY, and KPI calculations.
- **Microsoft Excel:** Data analysis, KPI reporting, and dashboard development.
- **Power BI:** Dashboard design, interactive reporting, and data visualization.
- **Business & Financial Analytics:** Loan portfolio analysis, verification, delinquency, and default risk analysis.
- **Data Visualization:** Presenting key metrics through clear and informative dashboards.
- **Analytical Thinking:** Converting banking data into meaningful business insights.

## 📊 Key Performance Indicators (KPIs)

- Total Loan Accounts
- Total Funded Amount
- Total Interest Received
- Average Interest Rate
- Delinquent Loans
- Default Loan Rate
- Unverified Loans
